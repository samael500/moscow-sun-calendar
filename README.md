# Sun Calendar — восходы и закаты

116 городов России, Украины и Беларуси: включая все областные центры Украины, восемь городов Крыма и 13 крупных городов Беларуси, выбор на карте и поиск. На карте украинские и крымские города объединены в область «Юг» (51 город). Для каждого города — отдельный ICS: 6 календарных месяцев назад и 6 вперёд, события по 10 минут. В полярный день/ночь несуществующий восход или закат пропускается. Расчёт Astral, округление до минуты, открытый горизонт в центре города.

Опубликованный календарь: **https://brodov.net/sun-calendar/**. ICS: `https://brodov.net/sun-calendar/<city-id>.ics`, для Москвы `moscow.ics`. Раздел опубликован на brodov.net; ежедневное обновление настроено на 05:43 Москвы. Прежняя GitHub Pages-публикация этого репозитория на унаследованном домене maks.live отключена.

## Сборка

Python 3.12+:

```sh
python3 -m venv .venv
.venv/bin/pip install -r requirements.txt
.venv/bin/python -m unittest -v
.venv/bin/python generate.py
python3 -m http.server 8784 --directory docs
```

`--output-dir` задаёт каталог результата, `--start YYYY-MM-DD` — опорную дату, `--months 6` и `--history-months 6` — окно. По умолчанию опорная дата определяется в часовом поясе каждого города. UTC сохраняет правильный момент события; приложение показывает его в своём часовом поясе. UID Москвы совместимы с прежним календарём. Файл имеет конечное число событий, без RRULE. Чтобы отключить историю, укажите `--history-months 0`.

Результаты не хранятся в Git: `docs/` — выходной каталог. GitHub Actions проверяет генератор и сохраняет готовый сайт как артефакт. Репозиторий brodov.net подключает конкретный проверенный коммит sun-calendar как submodule и генерирует свежие ICS при каждой сборке; код автоматически из main не подтягивается. Ежедневную публикацию выполняет workflow сайта. Для обновления кода нужно обновить ссылку submodule через ревью сайта. GitHub может отключить ежедневное расписание после 60 дней отсутствия активности — проверяйте Actions, при необходимости включайте снова. Если обновление прекращается, последняя опубликованная версия остаётся доступной.

## Подключение

Добавьте подписку по URL, а не импорт файла. Google Calendar: «Другие календари» → «+» → «Добавить по URL». Apple Calendar: новая подписка. Outlook: подписка из интернета. Частоту синхронизации определяет приложение. События прозрачные для занятости, напоминаний нет. Изменение домена требует подключения новой ссылки; стандарт ICS не гарантирует автоматический перенос подписки. Не подключайте старую и новую московскую подписку одновременно.

## Данные и дизайн

Координаты и часовые пояса: GeoNames. Береговая линия: Natural Earth. Подробности и лицензии в [data/README.md](data/README.md). Карта работает локально, без ключей и сторонних тайлов. Для плотных областей доступны группы с выбором города, масштабирование, четыре региональных вида и поиск. Без JS доступны прямые ссылки на все ICS.

Оформление brodov.net: бумага #FFFDF9, чернила #35312F, вторичный текст #77675B, линии #E9DED3, Literata и PT Sans. Логотип не изменялся и не перерисовывался.

Области карты: «Запад» — Беларусь и западная Россия до Самары, «Юг» — 51 ранее объединённый город, «Центр» — Урал и Сибирь, «Восток» — Забайкалье и Дальний Восток. Обзор «Вся карта» сохранён. Высота карты сохраняется при переключении областей; названия областей также поддерживаются поиском.

Правила оформления, генераторы карты и OG-карточки, сравнение проекций и проверка интерфейса: [DESIGN.md](DESIGN.md).

## Общий стиль (interface 1)

Единственный источник палитры, локальных шрифтов и общих компонентов —
`vendor/brodov-style`, Git submodule на выбранном коммите. Инициализация:
`git submodule update --init --recursive`.
Самостоятельная сборка: `python generate.py --output-dir docs`.
По умолчанию пакет и docs вычисляются относительно generate.py, а не cwd.
`python generate.py --style-dir /path/to/brodov-style --output-dir /tmp/calendar`
явно заменяет пакет календаря. Внутри brodov.net передаётся пакет **блога**:
у обеих опубликованных частей один источник оформления.
Отсутствующий/несовместимый пакет — ошибка, старой встроенной копии нет.
Готовые CSS/woff2/брендовые PNG копируются локально, без CDN и GitHub runtime.

Обновление: сначала опубликовать коммит brodov-style, затем
`git -C vendor/brodov-style fetch origin` и
`git -C vendor/brodov-style checkout <tag-or-sha>`, проверить сборку и включить
новый gitlink в PR. Никаких `submodule update --remote` в CI.
Править общие значения следует в пакете; `web/map-tokens.css`, география,
компоновка и поведение карты остаются местными. OG-композиция сохраняется;
`design/social.html` читает те же шрифты и токены пакета.
