# Оформление солнечного календаря

Календарь — внутренняя страница «Бродов нет». Дизайн изолирован в `web/`: глобальные стили блога, его логотип, расчёты Astral, каталог городов и адреса ICS не меняются. Обновление дизайна в продакшене проходит через ревью и обновление submodule в brodov.net.

## Токены и типографика

`vendor/brodov-style/tokens.json` — единый источник утверждённых токенов: бумага `#FFFDF9`, текст `#35312F`, вторичный текст `#77675B`, линии `#E9DED3`, терракота `#8B593D`, абрикос `#F6DFCA`, текст кнопки `#714A32`. Максимальная ширина внешнего контейнера 1160px, отступы 40px / 22px до 600px включительно из `.brodov-container`. Локальные Literata (variable) и PT Sans побайтно совпадают с файлами блога; лицензии сохранены. Literata используется для текста, заголовков и времени; PT Sans — для интерфейса и пояснений. Обновлять шрифты только в brodov-style, не заменять системным начертанием.

В шапке название ведёт на главную, подзаголовок переносится. Вступление сохранено. Активная область карты подчёркнута, выбранный город отмечен абрикосовой заливкой. Обычные ссылки остаются ссылками; кнопкой оформлена подписка. В карточке порядок: город → дата и местное время → восход/закат → подписка → ссылка/копирование/скачивание → период и пояснения. В полярный период текст отсутствующего события имеет отдельный размер, чтобы не ломать карточку.

## Книжный атлас

Суша Natural Earth 1:110m; крупная гидрография Natural Earth 1:50m. Локальные данные, лицензия, критерии отбора и воспроизводимая подготовка описаны в [data/README.md](data/README.md). Изображение построено программно, без ручного рисования берегов/перемещения городов и без стороннего сервиса. Точки вычисляются из неизменённых координат каталога.

Выбрана [Lambert Conformal Conic](https://proj.org/en/stable/operations/projections/lcc.html):

```text
+proj=lcc +lat_1=45 +lat_2=65 +lat_0=55 +lon_0=100 +datum=WGS84 +units=m +no_defs
```

Стандартные параллели охватывают основную полосу городов, центральный меридиан близок к середине диапазона долгот. Контекст суши обрезается далеко за охватом городов: −35–235° долготы, 5–88° с.ш., чтобы искусственная граница обрезки не выглядела береговой линией в видимой области. Суша, реки, озёра и города используют один преобразователь WGS84 → LCC. Геометрии у 180° разделяются до проекции; тест проверяет непрерывность ±180°. Области вычисляются заново по проецированным координатам городов, старые viewBox не используются. Названия регионов — навигационные области, государственные границы не показываются. Соседние города, попавшие в видимую область, тоже доступны.

Сравнение выполнено при одинаковых шрифтах, палитре, размере карты, правилах группировки и подписей. Исходная формула сохранена как `--projection linear`.

| Ширина / область | Линейная: группы и одиночные цели / подписи | Коническая: цели / подписи |
| --- | --- | --- |
| 390px / вся карта | 5 / 5 | 6 / 8 |
| 390px / Запад | 6 / 14 | 8 / 15 |
| 1280px / вся карта | 19 / 12 | 20 / 12 |
| 1280px / Запад | 17 / 22 | 20 / 22 |

В обоих общих видах доступны все 116 городов. Коническая карта лучше заполняет высоту телефона и даёт больше раздельных целей выбора; выбранные крайние города и подписи остаются внутри поля. Поэтому выбран конический вариант. Это сравнение конкретного охвата, не утверждение об универсальном превосходстве проекции.

Высота карты 430px на desktop/tablet и 320px до 700px включительно, постоянная для всех областей. SVG геометрия масштабируется внутри фиксированного окна; подписи, кружки и HTML-области нажатия сохраняют размер в экранных пикселях. Цели 44×44px, пересекающиеся цели объединяются по центроидам до устранения пересечений. Число на значке — группа, а не смещённая точка города. Все точки остаются в своих координатах. Группа открывает список с полными названиями и кнопкой приближения; точки группы также открывают этот список при клике. Поиск доступен независимо от карты.

Подписи отбираются с приоритетом выбранного города и проверкой пересечений. Выбранная подпись удерживается внутри поля и соединяется с точкой линией. Если пользователь переключил область далеко от выбранного города, название остаётся под картой; «Показать на карте» возвращает его в видимую область. Выбор города через поиск/URL автоматически показывает нужную область. Невидимые точки не создают остановок Tab. Enter/Space открывают группу, Escape закрывает её с возвратом фокуса. Диалог немодальный, не запирает клавиатуру; кнопки и ссылки имеют focus-visible.

## Устойчивость

Данные городов загружаются первыми и активируют поиск/подписки независимо от карты. Ошибка SVG или метаданных проекции показывает короткое сообщение и сохраняет рабочий список. Ошибка cities.json раскрывает статические ссылки на все 116 ICS. Без JavaScript эти ссылки видны сразу. При запрете Clipboard API ссылка выделяется для ручного копирования.

## OG-карточка

Исходник `design/social.html`, генератор `scripts/build_social.py`. 1200×630px, Literata 500 и PT Sans из `vendor/brodov-style/fonts`, бумага/текст/терракота как на странице, простой знак солнца над горизонтом. Перед экспортом генератор явно загружает оба FontFace и проверяет `loaded`. Имя `social-<sha256[:12]>.png` меняется с пикселями; метаданные обновляются автоматически. `og:image`/`twitter:image` абсолютные, размер и alt заданы, `twitter:card=summary_large_image`. Старые файлы social.png/social.svg сохранены только для совместимости старых ссылок; новые карточки из них не строятся.

## Генерация и проверка

```sh
python -m pip install -r requirements-design.txt
python -m playwright install chromium
python scripts/build_map.py
python scripts/build_social.py
python -m unittest -v
python scripts/test_map.py
python generate.py --start 2026-09-23 --output-dir /tmp/sun-design-preview
python -m http.server 8790 --directory /tmp/sun-design-preview
# В другом терминале:
python scripts/test_ui.py --output /tmp/sun-ui-review
python scripts/compare_projections.py --output /tmp/sun-projection-review
```

Для установленного браузера передать `--browser /path/to/chromium` в браузерные скрипты. Дизайнерские зависимости не нужны для ежедневной генерации ICS. CI проверяет карту и интерфейс отдельно от календарных тестов, сохраняет скриншоты как артефакт.

Проверка 23.09.2026 в Chromium: ширины 360/390/768/1280; все пять видов, постоянная высота и положение блока ниже; отсутствие горизонтального скролла, пересечений целей и подписей, обрезания подписей; Москва, Калининград, Мурманск, Владивосток, Анадырь; hash и reload; ё/е и пустая выдача; копирование и отказ Clipboard API; URL подписки/скачивания; сбой обоих файлов карты, сбой cities.json, отключённый JS; Enter/Space/Escape, видимый фокус, масштабирование. Семь календарных тестов и три географических теста проходят. При одинаковой опорной дате все 116 ICS побайтно совпадают с исходной версией.

До изменений в опубликованной версии воспроизведены: разная высота карты между регионами (на 360px 121–432px), 116 фокусируемых маркеров даже за пределами области, отсутствие подписи выбранного Анадыря и недоступность динамического списка при отказе map.svg. Эти сценарии исправлены и покрыты проверками.

Контраст sRGB: текст/бумага 12,67:1; вторичный текст/бумага 5,33:1; текст кнопки/абрикос 5,99:1; подписи/суша 6,41:1. Точные результаты автоматического расчёта сохранены в отчёте проверки.

Не проверены вручную: физические устройства и жесты, Safari/Firefox, программы экранного доступа, обновление подписок внутри Google/Apple/Outlook, обновление кешей социальных сетей после публикации. Автотесты не заменяют эти проверки.

## Общий источник оформления — 23.09.2026

Ранее скопированные `web/tokens.css` и `web/fonts/` заменены зафиксированным
`vendor/brodov-style` (interface 1). Редактируемый источник — этот репозиторий,
а не локальные копии. Общие переменные имеют префикс `--brodov-`; карта
сохраняет свои географические переменные в `web/map-tokens.css`.
Общие CSS подключаются первыми, локальная компоновка — после них.
См. README для standalone/--style-dir и обновления submodule через PR.

Поиск и поле ссылки используют `.brodov-input`. Локальны ширина/высота,
компактный вторичный текст ссылки и общая линия группы поле + копирование
(без второй линии у самого input). Фокус — из общего base.css; карта
сохраняет свой внутренний outline-offset, чтобы обводка не обрезалась.
Порог контейнера общий 600px; перестройка содержимого остаётся на 700px.
